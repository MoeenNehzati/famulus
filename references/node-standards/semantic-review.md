# Node Standards Semantic Review Instructions

## review-identity
Check naming, discovery, taxonomy, legacy compatibility, and permission semantics that require contextual judgment.

## review-blueprint
Check graph authority, ownership, behavioral-source, hashing, and certification meaning beyond schema validity.

## review-interfaces
Check whether source-owned interfaces describe their actual public contracts and immediate I/O without leaking internals.

## review-runtime
Check runtime-layer boundaries, import discipline, injection lifecycle, and whether prose names public interfaces rather than private paths.

## review-state-security
Check state ownership, credential placement, and whether declared filesystem effects match actual behavior.

## review-portability
Check host-neutrality claims and whether platform-specific behavior is isolated and truthfully declared.

## review-instructions
Check trigger quality, terseness, neutrality, and whether the skill body contains only behavior-shaping instructions.

## review-workflow
Check system-level coordination, current-session change scope, and whether validation and publication instructions fit the requested workflow.

## review-validation
Check whether each normative rule has the strongest honest mechanical coverage and whether the declared limitations capture the remaining semantic gap.
