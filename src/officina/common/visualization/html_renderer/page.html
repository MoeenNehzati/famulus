How to use
Double-click a node to hide it; use the Hidden nodes list in the left inspector to restore it.
Toolbar (top-left, always visible): Highlight ancestors cycles focus for the primary node; Hide selected and Dim selected act on the complete selection; Redraw all resets layout.
Hover a node or edge to preview metadata. Click to pin details in the left inspector.
Click a node to select it; hold Ctrl/Cmd to toggle multiple nodes. Find selects matching nodes and both endpoints of matching relations. Click a node or edge type in the legend to hide or show that type.
h cycles ancestor focus (off → dim → hide). Esc or ✕ deselects. r redraws. c restores nodes and focus; Shift+C also clears filters and legend exclusions. f fits the graph.
Drag a node to reposition it. Drag a sidebar edge or focus its resize handle and use arrow keys to adjust width.
Scroll to zoom in/out (centered at cursor). Drag empty space to pan. Use the toolbar +/−/Fit buttons or keyboard + − f.
Edge styles: solid = Verified; long-dashed = Likely; short-dashed = Speculative. Node borders: solid = explicit; dashed = model-introduced.
