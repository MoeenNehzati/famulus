How to use
Double-click a node to hide it; use the Hidden nodes list in the left inspector to restore it. Alt+double-click a container to collapse or expand its contents instead.
Toolbar (top-left, always visible): Hide selected and Dim selected act on the complete selection; Redraw all resets layout.
Hover a node or edge to preview metadata. Click to pin details in the left inspector.
Click a node to select it; hold Ctrl/Cmd to toggle multiple nodes. In a multi-selection, click a selected-node name to inspect it or double-click it to remove it from the selection.
The node and color legends select matching nodes. Arrows beside Relations add ancestors or successors through every visible relation type; relation-row arrows restrict traversal to that type. Existing hide and dim buttons act on the resulting selection. Click the rest of a relation row to hide or show that relation.
Esc or ✕ deselects. r redraws. c restores hidden nodes; Shift+C also clears filters and legend exclusions. f fits the graph.
Drag a node to reposition it. Drag a sidebar edge or focus its resize handle and use arrow keys to adjust width.
Scroll to zoom in/out (centered at cursor). Drag empty space to pan. Use the toolbar +/−/Fit buttons or keyboard + − f.
Edge styles: a single-relation edge uses the color and dash pattern shown under Relations. Metadata-driven changes are explained under Edge presentation. Node borders: solid = explicit; dashed = model-introduced.
